1. useViewerSync — API Incompleta

Arquivo: src/hooks/useViewerSync.ts

APIs existem mas não estão completamente funcionais:

  • saveViewerSnapshot() → Retorna null
  • restoreViewerSnapshot() → Não tem viewer registrado
  • enable2DView() → Placeholder sem implementação
  • renderScene() → Placeholder sem implementação

Recomendação: Implementar completamente ou remover da UI.

2. RoomBuilder.ts — Stub Desabilitado

Sistema de sala foi removido temporariamente mas o RoomBuilder mantém API pública sem lógica real. Todos os métodos retornam valores vazios.

Recomendação: Deletar ou documentar como "em desenvolvimento".

3. ThreeViewer — Props Não Uútilizadas

Componente recebe 6 props que nunca sóo usadas: cubeCount, cubeSize, animationEnabled, materialId, showFloor, colorize

Recomendação: Remover props não uútilizadas.

4. Duplicação: updateWorkspacePosition vs updateWorkspaceBoxPosition

Duas funções fazem exatamente a mesma coisa (aliases): 

updateWorkspacePosition: (boxId, posicaoX_mm) => { ... }
updateWorkspaceBoxPosition: (boxId, posicaoX_mm) => { ... } // Chama updateWorkspacePosition

Recomendação: Remover um dos aliases.
