3.4 src/services/boxLayersService.ts [NOVO]

Funções Exportadas
  • regenerateLayersForBox(box: WorkspaceBox) → gera doorsLayer + drawersLayer automaticamente
  • createManualDoor(box: WorkspaceBox) → cria DoorLayerItem default
  • createManualDrawer(box: WorkspaceBox) → cria DrawerLayerItem default
Lógica de Regeneração:
  • Se portaTipo = "porta_simples" → gera 1 porta centrada
  • Se portaTipo = "porta_dupla" → gera 2 portas metade cada
  • Se portaTipo = "sem_porta" → 0 portas
  • Para cada gaveta configurada → gera DrawerLayerItem

7. SISTEMA GRANDE CRIADO: Doors/Drawers Engine 2.0

7.1 Arquitetura Geral

Camada 1: Tipos (Type Safety)
DoorLayerItem | DrawerLayerItem → definem estrutura completa

Camada 2: Geração (Business Logic)
boxLayersService.regenerateLayersForBox() → auto-gera baseado em config

Camada 3: State Management (Actions)
13 ProjectActions → controlam CRUD de camadas

Camada 4: Sincronização (Data Flow)
useCalculadoraSync → passa dados ao Viewer

Camada 5: Renderização (3D)
BoxBuilder → cria THREE.Group por porta/gaveta

Camada 6: UI (User Interface)
BoxLayersPanel + DoorsDrawersLayersPanel → controle total

7.2 Fluxo de Dados Completo

User Action (Add Door via UI) ↓ BoxLayersPanel.tsx onClick → actions.addDoorLayerItem() ↓ ProjectProvider.tsx (addDoorLayerItem action) ↓ createManualDoor(box) → retorna DoorLayerItem novo ↓ updateProject() → mapeia box, adiciona ao doorsLayer ↓ recomputeState() → atualiza WorkspaceBox na state ↓ useProject() hook rebind → React re-renders ↓ useCalculadoraSync detecta mudança ↓ Viewer.updateBox() chamado ↓ BoxBuilder.buildBoxLegacy() recebe doorLayerItems ↓ buildDoorSpecs(doorLayerItems) converte para specs ↓ createDoorObject(spec) → cria THREE.Group com geometry ↓ group.add(doorObject) → adiciona ao boxGroup ↓ 3D Scene renderiza porta nova ↓ User vê porta no canvas!

7.3 Configurabilidade

Tudo é configurável via rules.furos.tecnicos:
  • Cavilha: posição, tamanho, profundidade, qual faces aplicar
  • Parafuso: offset, profundidade igual espessura ou não
  • Dobradiça: posição lateral, vertical fixo ou array custom
  • Corredica: offset frente/fundo, altura relativa
  • Prateleira: espaçamento, margens, num furos por coluna

7.4 Extensibilidade

  • Novo tipo de porta: Adicionar case em regenerateLayersForBox()
  • Novo tipo de animação: Actualizar createDoorObject() em BoxBuilder
  • Novo tipo de material: Sistema material existente já suporta
  • Nova regra de furação: Adicionar função em drillingService.ts
