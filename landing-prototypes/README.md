# Pimo-Criativo Landing Page Prototypes

This folder contains **three independent landing page concepts** for the pimo-criativo project. Each prototype is fully isolated and does not interact with core engine files, 3D systems, or large modules.

## Concepts

- **concept1-modern**: Modern, visually rich layout with animated cabinet preview (canvas).
- **concept2-minimal**: Minimalist, clean layout with animated bar and simple navigation.
- **concept3-creative**: Creative, playful layout with interactive demo area and vibrant colors.

## Usage

Open any HTML file in a browser to preview the landing page. All assets are self-contained and optimized for performance and modular integration.

## Technical Constraints
- No imports from core/engine/viewer/ruler/project subsystems.
- No heavy modules or 3D engines.
- All code and assets are contained in this folder.
